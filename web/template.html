Is it like ChatGPT?

No. It uses the same core idea, a Transformer that predicts what comes next, but it is about 214,000 times smaller than GPT-3 and only ever read Shakespeare. It was never taught to chat, so it treats a question as the start of a script. Try "Ask a question" to see.

  • Can: keep the format of a play, invent speakers, spell most words, keep the rhythm of verse.
  • Cannot: answer questions, follow instructions, write about a topic you choose, make sense across lines, or remember more than 64 characters.
  • Only knows 65 characters: most digits, symbols like @ # + / and emoji are dropped.

How it writes

Each step, the model looks at the last 64 characters and scores all 65 characters it knows. Softmax turns the scores into the probabilities in the bars, and it picks one at random in proportion to them.

Inside, four Transformer blocks let every character attend to the characters before it. The attention strip shows where it looked for the current guess. It has no idea what any word means, so it writes things that sound right but rarely make sense.
